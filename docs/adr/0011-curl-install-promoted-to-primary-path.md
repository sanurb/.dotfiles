# ADR-0011: Curl-install promoted to a peer of Homebrew and `nix run`

`dots` previously framed curl-install as a fallback whose long-term status was deferred (AGENTS.md §6). The release pipeline already produces signed, OIDC-keyless artifacts that pass the same cosign + SHA-256 verification as the Homebrew tap downloads from. Holding the curl path in "deferred" status while delivering a fully-attested binary on every release contradicts Honesty (priority #1) — pretending we're still deciding when the artifacts already exist. PR #4 promotes the curl path to a peer of Homebrew and `nix run`. Three entry points; pick by which package manager you already use.

To make the curl URL stable across releases, GoReleaser now publishes raw binaries with version-less filenames — `dots-darwin-arm64`, `dots-darwin-amd64`, `dots-linux-amd64`, `dots-linux-arm64` — alongside the existing versioned `dots_<v>_<os>_<arch>.tar.gz` archives that Homebrew consumes. The stable URL `https://github.com/sanurb/.dotfiles/releases/latest/download/dots-<os>-<arch>` resolves regardless of the current tag, so the curl one-liner does not change at release time. Cosign signatures and CycloneDX SBOMs cover the new raw binaries automatically because the existing `signs:` and `sboms:` blocks match `artifacts: archive`, which fires on every `archives:` entry regardless of format. `scripts/install.sh` was reduced — no more tar extraction; the script downloads the raw binary, verifies, and `install`s it.

Platform scope is declared explicitly: macOS and Linux only. `nh` and Moon do not have Windows ports; publishing a Windows binary that cannot run `dots deploy` would advertise support the product does not deliver, again violating Honesty. Windows users run dots inside WSL2. A future Windows-native story is a separate ADR if `nh` or an equivalent realization driver ports.

Trade-offs: the curl path is now part of the release surface area we promise to keep working — bumping the install script's URL pattern requires a deprecation window, and the SHA256SUMS layout is part of the contract third-party reproducers (e.g. nix-installer-style verifiers) may consume. Alternative considered: dropping the tar.gz archives entirely and shipping only raw binaries. Rejected — the Homebrew formula consumes the tar.gz, and a LICENSE/README pair alongside the binary is what users dropping the archive into `/usr/local` expect. Keeping both costs nothing on the publisher side.
